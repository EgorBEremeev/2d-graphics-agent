# Матрица возможностей

Статус интерфейса: DISCOVERED, INSTALLED, PROBED, VALIDATED, UNSUPPORTED, BROKEN, STALE, NOT_TESTED. Наличие skill, его выбор агентом и эффективность операции учитываются отдельно. Изменение версии делает затронутые гарантии STALE, а не запускает массовую перепроверку. Среда: Windows / проектный .venv-graphics; пути восстановления — [среда](../environment/2d-environment.md).

Все исторические статусы и версии относятся к исходной установке; состояние установки нового владельца до проверки — NOT_TESTED. Перенос файлов не подтверждает установку или работу.
