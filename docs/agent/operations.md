# Карта операций 2D-агента

## Маршруты по смыслу операции

Для каждой строки применяются [контракты A/B/P](graphics-data-contracts.md). Конкретный установленный исполнитель, его вход и подтверждённые пределы выбираются по [матрице](capability-matrix.md). Таблица определяет класс решения; наличие названного предметного навыка проверяется отдельно.

| Триггер и смысл | Вход | Домен | Класс операций | Компетенция / класс исполнителя | Выход | Выбор и fallback | Существенная итоговая проверка |
|---|---|---|---|---|---|---|---|
| Изменить существующие пути | Векторная геометрия и требуемая операция | A/B/P по назначению | Boolean, упрощение, stroke-to-path, топология | Native vector engine / совместимый geometry runner | Редактируемый документ с нужными ID | Только интерфейс существующих данных; неподдержанный action → известный fallback матрицы | Заданный геометрический эффект и критичные связи |
| Подготовить выпуск/печать | Готовая схема/изделие, профиль выпуска | P либо B→P | Prepress и экспорт | Подтверждённый renderer/exporter и независимый reader | PDF/PNG, при необходимости листы 1:1 | Для физического 1:1 нужен явный mapping и print profile; иначе presentation export | Страницы, шрифты, boxes, crop/масштаб по профилю |
| Создать простую карточку с нуля | Фигуры, текст, размеры композиции | A/P | Генерация примитивов | Подтверждённый native engine | Редактируемый проект и экспорт | Совместимый native engine | Фигуры и текст соответствуют заданию |
| Распределить копии по направляющей | Кривая, образец, параметры ориентации | A либо B при явных единицах | Распределение и пространственное преобразование | Штатная операция, [адаптация допуска](../../tools/inkscape/precise_distribution.py) | Ориентированные редактируемые копии | Точность выбирается по масштабу; не выдавать за тесселяцию | Положение, ориентация, допустимая ошибка |
| Построить технический чертёж / обмен | Точные конструкции и единицы | B / physical CAD | CAD, размерный обмен, plotter | Подтверждённый CAD API/CLI из матрицы | DXF/SVG/полилинии по заданию | Локально подтверждены только ограниченные операции; иной CAD → discovery | Размерная точность, замкнутость, корректность обмена |
| Непокрытая операция | Источник и требуемый графический эффект | Определить по назначению | Discovery → сравнение → проба | Поиск по официальным источникам, внешний инструмент либо узкий проектный стык | Контракт задания | reuse → adapt → build; новый стык только для доказанного пробела | Наблюдаемый эффект, пригодность результата |
| Восстановить чистый эскиз/орнамент | Контрастный растр с установленной ролью линий | A→A | Очистка, трассировка, восстановление областей | [sketch-mosaic-pre-vectorizer](../../.agents/skills/sketch-mosaic-pre-vectorizer/SKILL.md) | artwork_regions.svg + manifest | silhouette либо separators по смыслу; неоднозначность → NEEDS_REVIEW | Overlay, закрытость, отверстия и соседство |
| Восстановить композицию с фото кладки | Фото с историческими швами | A→A | Семантическая сегментация и реконструкция | photo-mosaic-pre-vectorizer, ABSENT | Художественные области | Discovery готового workflow; не заменять обычной бинаризацией без основания | Художественные массы сохранены; старые швы не превращены в зоны |
| Пронумеровать цветные области | Готовые замкнутые цветные зоны | A→A | Пространственный анализ, метки, выноски | [inkscape-cli-mosaic-labeler](../../.agents/skills/inkscape-cli-mosaic-labeler/SKILL.md) либо vector-svg-to-numbered-contours (ABSENT) | structural_layout.svg + palette_map.json | Выбирается один совместимый labeler; второй — альтернатива при конкретной причине | Метка в своей видимой зоне/выноска, палитра и неизменные контуры |
| Собрать схему, образцы и легенду | Готовый artwork/схема + palette + layout | A→P; B→P только с print profile | Document Assembly, недеструктивная компоновка | [document-assembly](../../.agents/skills/document-assembly/SKILL.md) | Листы SVG + manifest + preview/export | Параметризованный assembler; сложный импорт → нормализация либо квалифицированный отказ; B→P пока не поддержан | Полная читаемая легенда, page bounds, source→page mapping |
| Создать физическую кладку | Artwork и явные размеры, швы, andamento | A→B | Тесселяция и производственная геометрия | tessellation-mosaic-generator, ABSENT | scaled_artwork, scale_mapping, flow_lines, final_layout, tiles_manifest | Отдельная компетенция; неподтверждённое средство → discovery; сетка не заменяет заданные направляющие | Миллиметры, реальные зазоры, подрезки, пересечения и идентичность тайлов |

Координаты, стабильные ID и манифесты определяются единым контрактом, а не этой таблицей. 02/03/04 — самостоятельные будущие компетенции; наличие постановки не доказывает их реализацию. Принятый совместимый маршрут применяется без повторного discovery.

## Контракты и приёмка

Координаты A/B/P, устойчивые ID, палитра, манифесты и переход artwork→изделие определены в [едином контракте данных](graphics-data-contracts.md). Область поддержанных SVG-конструкций и действительные команды принадлежат соответствующему skill и [матрице](capability-matrix.md). Эта карта выбирает маршрут и не дублирует их спецификации.

Исторические приёмки относятся к исходной установке. Установка средства, обнаружение skill, выбор агентом и эффективная операция учитываются отдельно. Физический принтер требует отдельного испытания.
