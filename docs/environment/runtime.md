# Использование подготовленной среды

## Подключение подготовленной среды

Открой корень проекта в PowerShell 5.1 и прочитай актуальную [карту среды](2d-environment.md). Выбери строку нужного средства, его точку входа, исполняющее окружение и настройки из записи; не предполагай, что все компоненты библиотеки были установлены. Если записи или нужного компонента нет, подготовь его по [setup](setup.md), запиши фактический результат в карту и затем вернись к вызову.

```powershell
$root = (Get-Location).Path
$mapPath = Join-Path $root 'docs\environment\2d-environment.md'
$mapText = [IO.File]::ReadAllText($mapPath, [Text.UTF8Encoding]::new($false, $true))
```

Агент читает `$mapText` и сам выбирает `$recordedPath` из соответствующей строки. Если там записан относительный проектный путь, вычисли абсолютный; если абсолютный, используй его как записано. Не подставляй имя или расположение другого средства:

```powershell
if ([IO.Path]::IsPathRooted($recordedPath)) {
    $entryPoint = [IO.Path]::GetFullPath($recordedPath)
} else {
    $entryPoint = [IO.Path]::GetFullPath((Join-Path $root $recordedPath))
}
if (-not (Test-Path -LiteralPath $entryPoint)) { throw 'Указанный в карте компонент отсутствует; выполни setup и обнови карту.' }
```

По фактически записанной установке и документации выбранного модуля агент назначает нужные переменные **только текущему процессу**, а не глобальной конфигурации. Например, для переменной `$variableName` со значением `$variableValue`:

```powershell
[Environment]::SetEnvironmentVariable($variableName, $variableValue, 'Process')
```

Пути к venv, Python, приложениям, профилям, кэшам и шрифтам и имена требуемых переменных берутся из карты и документации соответствующего средства. Не активируй отсутствующее окружение и не повторяй установку всей библиотеки при каждом входе.

## Использование точек входа

Вызывай найденный исполняемый файл или Python окружения с параметрами выбранной задачи; действующие точки входа и особенности переносимых утилит — в [каталоге tools](../../tools/README.md), предметные параметры — в соответствующих skills. Если модуль требует передать скрипт конкретному Python, используй Python именно его окружения; встроенные интерпретаторы приложения и внешние venv остаются раздельными. Для путей с пробелами передавай каждый путь отдельным аргументом PowerShell. Факт доступности точки входа сам по себе не подтверждает графический эффект.

## Профили и временные данные

Размещение и настройки профиля конкретного средства выбирай по его записи в карте и документации. Для существующих библиотечных runners механизм изоляции — `tools/inkscape/runtime.py`: он создаёт временную среду в проектном `.cache/graphics`, устанавливает временные каталоги и профиль дочернего процесса. Особенности профиля расширения и способ его установки по запросу указаны в [каталоге tools](../../tools/README.md) и соответствующем skill. Общие правила сохранности и очистки — в [операционном контракте](../agent/graphics-model-behavior.md).
